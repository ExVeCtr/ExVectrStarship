# Flight Log

> One entry per flight, newest first. Each flight has an annotated tag `flight/NNN` on `master` (see [development-workflow.md](development-workflow.md#post-flight-backup)). Flights before this log was started (Nov 2026) are not tagged.

## Template

```markdown
## flight/NNN (YYYY-MM-DD)
- **Commit:** <master hash>  **Tag:** flight/NNN
- **Mission:** <mission chain / waypoints flown>
- **Goals:** <what this flight was meant to verify>
- **Conditions:** <site, wind, temperature, battery>
- **Outcome:** <success / partial / failure: one line>
- **Timeline:** <key events with mission time>
- **Anomalies:** <what went wrong or looked odd>
- **Data:** <links/paths to logs, video>
- **Follow-ups:** <issues created, doc updates needed>
```
